# 사진만 받는 Google Apps Script 업로드 화면

이름·이메일 질문 없이 사진만 받습니다. Google Forms에 붙이는 소스가 아니라, Google Apps Script에서 웹 앱으로 배포하는 두 파일입니다. 청첩장에는 사진 선택란이 없고, 이 웹 앱으로 이동한 후 사진을 선택합니다.

## 설치

1. https://script.google.com 에서 새 프로젝트를 만듭니다.
2. 기본 `Code.gs`를 이 폴더의 `Code.gs` 내용으로 교체합니다.
3. **+ → HTML**로 `Index` 파일을 만들고 `Index.html` 내용을 붙입니다.
4. 편집기에서 `setupPhotoDrop_` 함수를 한 번 실행하고 본인 Google Drive 접근 권한을 승인합니다. 본인의 Drive에 비공개 `하객 웨딩 사진 2027-04-17` 폴더가 생성됩니다.
5. **배포 → 새 배포 → 웹 앱**에서 **실행 사용자: 나**, **액세스 권한: 모든 사용자(Anyone)**로 배포합니다. 조직 계정 정책에 따라 이 옵션이 없으면 개인 Google 계정을 사용하거나 관리자 설정이 필요합니다.
6. 발급된 `https://script.google.com/macros/s/.../exec` 주소를 청첩장의 `config.js` → `photoDrop.uploadUrl`에 넣습니다. `/dev` 주소는 하객용이 아닙니다.

Google Drive 폴더를 공개하거나 편집 권한으로 공유할 필요가 없습니다. 로그인 없이 받으려면 반드시 '모든 사용자'로 배포하고 시크릿 창에서 확인하세요. 실제 Google 계정에 배포하는 작업은 사용자가 진행해야 합니다.

## 현재 임시 테스트 및 기존 배포 업데이트

현재 소스는 한국 시간 **2026-11-15 22:15까지** 시험 업로드를 허용합니다. 이후 자동으로 원래 예식 접수 기간만 허용합니다. 이미 웹 앱을 배포했다면 편집기의 `Code.gs`를 새 내용으로 교체한 뒤 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 선택하세요. 기존 웹 앱 주소를 유지할 수 있습니다. 청첩장 코드만 바꾸는 것으로는 Google 서버의 접수 제한이 해제되지 않습니다. 시험 후 즉시 닫으려면 `testUntil`을 빈 문자열로 바꾸고 같은 방식으로 재배포하세요.

## 기간과 제한

한국·일본 시간 2027-04-17 00:00부터 2027-04-24 00:00 전까지 받습니다. 한 번에 최대 10장, 한 장당 10MB이며 JPG/PNG/HEIC 파일 형식을 서버에서도 확인합니다. 원래 파일명 대신 임의 파일명으로 저장합니다. 총 1,000장 한도는 `Code.gs`의 `maxUploads`에서 조정할 수 있습니다. Google Drive 여유 공간과 Apps Script 할당량도 적용됩니다.

배포 전 시험하려면 `Code.gs`의 `opensAt`과 `closesAt`을 현재를 포함하는 짧은 기간으로 잠시 바꾸고 웹 앱에서 실제 사진 1장을 전송해 Drive 저장을 확인하세요. 시험 후 예식 기간을 복원하고 **배포 관리 → 수정 → 새 버전**으로 업데이트합니다. 청첩장도 예식 전에는 업로드 링크를 비활성화하므로 테스트는 웹 앱 주소에서 직접 진행합니다.

## 검증 범위

로컬에서 웹 화면 및 서버 로직을 모의 실행으로 검증했습니다. 실제 Drive 저장·Google 권한·익명 접근은 본인 Google 계정으로 웹 앱을 배포한 뒤 위 절차로 확인해야 합니다.
